# AI-Based Network Intrusion Detection and Real-Time Monitoring Web Platform

## Project Overview
An AI-based platform for analyzing network traffic, detecting potentially suspicious activity, and displaying results through a web dashboard.

## Objectives
- Analyze network traffic and relevant network-flow features.
- Develop and evaluate a machine-learning intrusion detection model.
- Provide a prediction API.
- Store detection events in PostgreSQL.
- Display monitoring information and security alerts through a web dashboard.

## Planned Technology Stack
- Frontend: React
- Backend: Node.js, Express.js, Socket.IO
- Machine Learning: Python, Pandas, NumPy, scikit-learn
- ML API: FastAPI
- Database: PostgreSQL
- Network Analysis: Wireshark, Scapy, and suitable datasets
- Version Control: Git and GitHub

## Development Phases
1. Project setup
2. Dataset preparation
3. Model development and evaluation
4. Prediction API
5. Backend and database integration
6. Frontend dashboard
7. Real-time alerts
8. Testing and documentation
